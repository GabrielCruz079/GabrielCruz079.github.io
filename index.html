Análise de Saúde Vacinal — Brasil (2015–2023)
Projeto de análise de dados de saúde pública com dados reais do governo brasileiro. Pipeline completo: banco MySQL com 4 tabelas, tratamento em Python com geração automática de 5 gráficos analíticos e dashboard interativo com mapa geográfico no Power BI. Identifica queda crítica de cobertura vacinal — de 96% em 2015 para 71,5% em 2023 — e correlação direta com surto de sarampo em 2019.
→ Destaques: dados reais do governo · mapa interativo · correlação sarampo × vacinação · meta OMS como referência

RH Analytics — Análise de Turnover

LogBrasil — Custo de Estoque por Filial
Análise completa de custo de estoque de uma distribuidora logística com 18 filiais distribuídas pelo Brasil. Pipeline completo: banco MySQL com 5 tabelas normalizadas, dados sintéticos com sazonalidade, 7 gráficos automáticos em Python, exportação para Excel com 6 abas e dashboard executivo no Power BI. Custo total anual de R$ 1,13 bilhão identificado com Sudeste representando 50% do custo.
→ Destaques: 18 filiais · sazonalidade simulada · R$ 1,13Bi em estoque · dashboard Power BI
